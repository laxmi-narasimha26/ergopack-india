# SEO Audit Report - Ergopack India (Code Review)

Generated by Codex from repository inspection only. No external crawl, Search Console, or analytics data was used.

## Scope and Method

- Reviewed Next.js metadata, robots, sitemap, and structured data implementation.
- Checked public assets referenced by metadata and JSON-LD.
- Compared public routes against sitemap entries and internal links.

## Assumptions

- Admin and presentation routes are not public and do not need full metadata.
- `NEXT_PUBLIC_APP_URL` is set correctly in production.

## Executive Summary

- Canonical handling likely collapses multiple pages to `/`, which can suppress indexing for non-home pages.
- Robots and sitemap sources conflict and contain stale or invalid URLs, risking crawl and index waste.
- Structured data is injected sitewide (FAQ) and includes placeholder or incorrect business data.
- OpenGraph and JSON-LD reference missing images, so social previews and schema validation are degraded.
- Keyword targeting is defined in `src/lib/seo-config.ts` but not applied to page metadata.
- Internal linking to high-value landing pages (ergonomics/EHS) is weak.

## Findings by Severity

### Critical

1. Canonical likely points to `/` on many pages
   - Root metadata sets `alternates.canonical` to `/` and many pages do not override it.
   - Risk: all pages canonicalize to home, reducing rankings for products, blog posts, and landing pages.
   - Evidence: `src/app/layout.tsx`, `src/app/page.tsx`, `src/app/blog/page.tsx`, `src/app/blog/[slug]/page.tsx`, `src/app/testimonials/page.tsx`.

2. Conflicting robots and sitemap sources
   - `public/robots.txt` and `src/app/robots.ts` conflict; only one should be served.
   - `public/sitemap.xml` and `src/app/sitemap.ts` conflict; only one should be served.
   - Risk: search engines see stale or incorrect URLs.
   - Evidence: `public/robots.txt`, `src/app/robots.ts`, `public/sitemap.xml`, `src/app/sitemap.ts`.

3. Sitemap contains non-existent or mismatched URLs
   - `public/sitemap.xml` lists `/industries/pharmaceutical` and similar routes that do not exist.
   - Uppercase product slugs in sitemap (`/products/700X`) conflict with lowercase canonical (`/products/700x`).
   - `src/app/sitemap.ts` includes `/support` which does not exist and omits `/ergonomics` and `/ehs-compliance`.
   - Evidence: `public/sitemap.xml`, `src/app/sitemap.ts`, `src/app/industries/page.tsx`, `src/app/ergonomics/page.tsx`, `src/app/ehs-compliance/page.tsx`.

4. Global FAQ schema on every page
   - `FAQSchema` is injected in the root layout and appears even on pages without visible FAQ content.
   - Risk: structured data guidelines violation.
   - Evidence: `src/app/layout.tsx`, `src/components/JsonLd.tsx`.

### High

1. Structured data uses placeholder or incorrect business info
   - Phone and address are placeholders or mismatch the footer.
   - Invalid `priceRange` string (`"ƒ,1ƒ,1ƒ,1"`).
   - Logo reference `/logo.png` does not exist.
   - Risk: schema errors and reduced local SEO trust.
   - Evidence: `src/lib/seo-config.ts`, `src/components/JsonLd.tsx`, `src/components/layout/Footer.tsx`, `public/images/logos/ergopack-logo.png`.

2. Product and article schema are client-only
   - Product JSON-LD is injected via `useEffect`.
   - Blog JSON-LD is injected in a client component.
   - Risk: crawlers may miss schema or see it late.
   - Evidence: `src/components/products/ProductPageTemplate.tsx`, `src/app/blog/[slug]/BlogPost.tsx`.

3. OpenGraph and JSON-LD image references are missing
   - `/images/og-image.jpg`, `/images/og/homepage.jpg`, `/logo.png` are referenced but not present.
   - Risk: broken social previews and schema warnings.
   - Evidence: `src/app/layout.tsx`, `src/lib/seo-config.ts`, `src/app/blog/[slug]/BlogPost.tsx`, `public/images`.

4. `metadataBase` can fall back to localhost
   - If `NEXT_PUBLIC_APP_URL` is not set, canonical and OG URLs point to localhost.
   - Risk: incorrect indexing signals.
   - Evidence: `src/app/layout.tsx`, `src/app/robots.ts`, `src/components/JsonLd.tsx`.

### Medium

1. Internal linking to key landing pages is weak
   - `/ergonomics` and `/ehs-compliance` are not in main navigation or footer.
   - Risk: lower internal PageRank and slower indexing.
   - Evidence: `src/components/layout/Footer.tsx`, `src/app/ehs-compliance/page.tsx`.

2. SearchAction points to missing `/search`
   - Structured data advertises a search feature that does not exist.
   - Evidence: `src/components/JsonLd.tsx`.

3. SEO config not used
   - `src/lib/seo-config.ts` defines rich keyword data but is not imported by pages.
   - Risk: inconsistent keyword targeting across pages.
   - Evidence: `src/lib/seo-config.ts`.

4. Stale `lastModified` in dynamic sitemap
   - Static pages use `new Date()` regardless of actual content updates.
   - Risk: unnecessary recrawls and low crawl efficiency.
   - Evidence: `src/app/sitemap.ts`.

### Low

1. PWA manifest references missing icons and screenshots
   - Not SEO-critical, but reduces install/preview quality.
   - Evidence: `public/manifest.json`, `public/icons`.

2. Meta keywords are included
   - Google ignores meta keywords, so they do not help rankings.
   - Not harmful, but not a priority.
   - Evidence: various `metadata` blocks.

## Public Pages Missing Explicit Metadata (Non-Admin)

These pages should define metadata + canonical explicitly if they are public:

- Home: `src/app/page.tsx`
- Testimonials: `src/app/testimonials/page.tsx`
- Compare: `src/app/compare/page.tsx`
- Compare Machines: `src/app/products/compare-machines/page.tsx`

If any of the presentation, demo, or internal tools are public, add metadata; otherwise apply `noindex`.

## Recommended Fixes (Prioritized)

### 1) Canonical and URL Hygiene

- Remove `alternates.canonical` from the root layout or override it on every public page.
- Add canonical URLs to all public pages.
- Normalize product URLs to lowercase and add redirects from alias slugs.
- Ensure sitemap URLs exactly match canonicals.

### 2) Single Source of Truth for Robots and Sitemap

- Remove `public/robots.txt` and `public/sitemap.xml` OR remove `src/app/robots.ts` and `src/app/sitemap.ts`.
- Update sitemap to include only real routes and correct casing.
- Make sure blog and marketing landing pages are included.

### 3) Structured Data Compliance

- Remove global FAQ injection from layout; include FAQ schema only on pages with visible FAQs.
- Fix business phone, address, and `priceRange`.
- Use the real logo path (or add `/public/logo.png`).
- Remove SearchAction or build a `/search` page.
- Move product and blog schema to server-rendered components.

### 4) OpenGraph and Social Previews

- Add missing OG images and update references.
- Ensure `metadataBase` is set in production.

### 5) Internal Linking and Content Coverage

- Add footer or nav links to `/ergonomics` and `/ehs-compliance`.
- Consider dedicated pages for industries if you want to target those terms.

- Keep them behind auth.
- Add `noindex` to their metadata or block them in robots.
