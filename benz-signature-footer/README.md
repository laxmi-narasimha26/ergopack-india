# Benz Packaging - Premium Signature Footer

A sophisticated, animated email signature footer for Benz Packaging Company.

## Features

✨ **Premium Animations**

- Shimmering gold metallic text effect
- Floating particle system
- Ambient light following
- Pulsing logo glow
- Smooth gradient border animation

🎨 **Design Elements**

- Deep dark theme with gold accents
- Glassmorphism-inspired styling
- Elegant corner accents
- Professional typography (Playfair Display + Montserrat)

📱 **Responsive & Accessible**

- 600x180px optimal size for email signatures
- Hover effects for interactivity
- Clean, minimal layout

## Usage

### As HTML Signature

1. Open `index.html` in a browser
2. Take a screenshot or use browser print to PDF
3. Convert to image format as needed

### Convert to GIF

To convert this animated signature to a GIF:

1. **Using Screen Recording:**
   - Open `index.html` in Chrome/Edge
   - Use Windows Game Bar (Win + G) or any screen recorder
   - Record 8-10 seconds of the animation
   - Convert the recording to GIF using tools like:
     - [ezgif.com](https://ezgif.com/video-to-gif)
     - [CloudConvert](https://cloudconvert.com/mp4-to-gif)

2. **Using Chrome DevTools:**
   - Open `index.html` in Chrome
   - Press F12 → More tools → Animations
   - Capture animation frames

3. **Recommended Tools:**
   - **ScreenToGif** (Windows) - Free, excellent quality
   - **LICEcap** (Windows/Mac) - Simple GIF capture
   - **Gifski** (Mac) - High-quality GIFs

## Customization

Edit `index.html` to customize:

- **Company Name:** Line 161 - `.company-name`
- **Tagline:** Line 162 - `.tagline`
- **Contact Info:** Lines 211-229
- **Colors:** CSS variables for gold (`#d4af37`, `#f4d03f`)
- **Background:** Gradient in `.signature-container`
